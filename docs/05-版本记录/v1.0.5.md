# v1.0.5 版本说明

**发布日期**: 2026-03-24

---

## 🐛 行为与一致性修复

### stopRecognition 行为说明修正

`stopRecognition()` 对应原生侧调用 `nui_dialog_cancel(false)`，SDK 不提供单独的 stop API，因此不保证一定返回最终识别结果。

---

## 🔧 原生与 TS 对齐

### 事件字段对齐（Android/iOS/TS）

- Android 事件补齐 `dialogId` 与 `wakeWord` 字段
- TS 事件数据类型补充 `isFinish` 字段，并在事件映射中接入 `wakeWord/isFinish`
- iOS 事件补充 `wakeWord` 字段

---

## 🛡️ 稳定性与兼容性

### Android logLevel 防越界

对 `logLevel` 入参进行边界保护，避免非法值导致数组越界崩溃。

### Android NativeEventEmitter 兼容

为 RN 事件订阅补充 `addListener/removeListeners` 空实现，避免部分 RN 版本告警。
