## 🐛 重要修复

### Android 代码与 AAR 不匹配修复

**问题描述**: 
Android 端代码使用了错误的包名和类名，导致无法编译：

| 错误内容 | 正确内容 |
|---------|---------|
| `com.alibaba.nuisdk` | `com.alibaba.idst.nui` |
| `NuiSdk` | `NativeNui` |
| `NuiSdkListener` | `INativeNuiCallback` |
| `NuiCallbackEvent` | `Constants.NuiEvent` |
| `NuiResultCode` | 使用 `int` 返回值 |
| `NuiVadMode` | 使用 `int` 参数 |

**修复内容**:
- 重写 `AliyunASRModule.java`，使用正确的 API
- 将 `NuiSdkListenerImpl.java` 重命名为 `NuiCallbackImpl.java`
- 实现 `INativeNuiCallback` 接口代替继承 `NuiSdkListener`
- 更新所有类型引用以匹配 AAR 实际内容

## 技术细节

### AAR 实际 API 验证

通过解压 AAR 确认的实际类结构：
```
com/alibaba/idst/nui/
  - NativeNui.class
  - INativeNuiCallback.class
  - Constants$NuiEvent.class
  - Constants$AudioState.class
  - Constants$LogLevel.class
  ...
```

### 回调事件映射

| AAR 事件 | 对应值 |
|---------|-------|
| EVENT_VAD_START | 0 |
| EVENT_VAD_TIMEOUT | 1 |
| EVENT_VAD_END | 2 |
| EVENT_ASR_PARTIAL_RESULT | 9 |
| EVENT_ASR_RESULT | 10 |
| EVENT_ASR_ERROR | 11 |

这些与 TypeScript 中的 `ASREvent` 枚举定义一致。
