# React Native 阿里云实时语音识别框架

基于阿里云 NUI SDK 开发的 React Native 实时语音识别库，仅专注于**实时语音识别**功能。

## 功能特性

- ✅ 实时语音识别 (Real-time ASR)
- ✅ 语音活动检测 (VAD)
- ✅ 中间结果实时返回
- ✅ 长文本连续识别
- ✅ 热词定制
- ✅ TypeScript 支持
- ✅ Android & iOS 双平台

## 系统要求

- React Native >= 0.60.0
- Android API 21+
- iOS 11+

## 安装

```bash
npm install @gaozh1024/rn-aliyun-asr
# 或
yarn add @gaozh1024/rn-aliyun-asr
```

### iOS 额外配置

```bash
cd ios && pod install
```

### 权限配置

#### Android (android/app/src/main/AndroidManifest.xml)

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

#### iOS (ios/YourApp/Info.plist)

```xml
<key>NSMicrophoneUsageDescription</key>
<string>需要麦克风权限进行语音识别</string>
```

## 快速开始

```typescript
import { AliyunASR, VadMode, ASREvent } from '@gaozh1024/rn-aliyun-asr';

// 获取实例
const asr = AliyunASR.getInstance();

// 初始化
await asr.initialize({
  appKey: 'your-app-key',
  token: 'your-token',
});

// 监听识别结果
asr.on(ASREvent.ASR_RESULT, (data) => {
  console.log('识别结果:', data.result?.text);
});

// 开始识别
await asr.startRecognition(VadMode.MODE_VAD);
```

## 基础用法

### 实时语音识别

```typescript
import { useEffect, useState } from 'react';
import { AliyunASR, VadMode, ASREvent, LogLevel } from '@gaozh1024/rn-aliyun-asr';

const asr = AliyunASR.getInstance();

function App() {
  const [result, setResult] = useState('');
  const [isRecording, setIsRecording] = useState(false);

  useEffect(() => {
    // 初始化 SDK
    asr.initialize({
      appKey: 'your-app-key',
      token: 'your-token',
      workspace: '/path/to/workspace',
      logLevel: LogLevel.INFO,
    });

    // 监听临时结果（边说边出结果）
    asr.on(ASREvent.ASR_PARTIAL_RESULT, (data) => {
      setResult(data.result?.text || '');
    });

    // 监听最终结果
    asr.on(ASREvent.ASR_RESULT, (data) => {
      setResult(data.result?.text || '');
      setIsRecording(false);
    });

    // 错误处理
    asr.on(ASREvent.ASR_ERROR, (data) => {
      console.error('ASR 错误:', data.errorMessage);
      setIsRecording(false);
    });

    // 清理
    return () => {
      asr.release();
    };
  }, []);

  const start = async () => {
    setIsRecording(true);
    await asr.startRecognition(VadMode.MODE_VAD);
  };

  const stop = async () => {
    await asr.stopRecognition();
  };

  return (
    <View>
      <Text>{result}</Text>
      <Button
        title={isRecording ? '停止' : '开始'}
        onPress={isRecording ? stop : start}
      />
    </View>
  );
}
```

### 热词定制

```typescript
await asr.startRecognition(VadMode.MODE_VAD, {
  vocabularyId: 'your-vocabulary-id',
});
```

## API 文档

详见 [API文档.md](./API文档.md)

### 核心方法

| 方法 | 说明 |
|------|------|
| `initialize(config)` | 初始化 SDK |
| `release()` | 释放 SDK 资源 |
| `startRecognition(vadMode, params)` | 开始识别 |
| `stopRecognition()` | 停止识别 |
| `cancelRecognition(force)` | 取消识别 |
| `on(event, callback)` | 订阅事件 |
| `off(event, callback)` | 取消订阅 |

### 事件类型

| 事件 | 说明 |
|------|------|
| `ASREvent.VAD_START` | 检测到语音开始 |
| `ASREvent.VAD_END` | 检测到语音结束 |
| `ASREvent.ASR_PARTIAL_RESULT` | 中间识别结果 |
| `ASREvent.ASR_RESULT` | 最终识别结果 |
| `ASREvent.ASR_ERROR` | 识别错误 |

## 注意事项

1. **Token 获取**：Token 有有效期，过期后需要重新获取
2. **音频权限**：确保应用有麦克风权限
3. **资源释放**：页面卸载时调用 `release()` 释放资源
4. **线程安全**：SDK 回调可能在非主线程，业务逻辑注意线程切换
