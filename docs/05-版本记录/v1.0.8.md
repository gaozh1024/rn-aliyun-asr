# v1.0.8 版本说明

**发布日期**: 2026-03-25

---

## 🛠 Android 录音链路修复

### 用户录音模式修正

- 修复 Android `enable_recorder_by_user` / `androidAudioConfig.recorderStrategy = 'user'|'auto'` 场景下的音频喂入方式
- `onNuiNeedAudioData(byte[] buffer, int len)` 现在会返回 `AudioRecord.read(...)` 的真实字节数
- 不再依赖独立线程 `updateAudio(...)` 推音频，避免 SDK 连续收到空音频后触发 `240052 / MIC_ERROR`
- 保留 `voiceRecognition -> mic -> default -> camcorder` 的录音 source fallback 逻辑

### 结果解析与事件管理优化

- `result.text` 默认输出解析后的纯文本，不再直接暴露阿里云原始 JSON 字符串
- 新增 `result.rawText` / `result.rawJson`，便于业务层保留原始返回值做调试
- SDK 重建原生事件订阅前会先移除旧订阅，降低重复订阅风险
- `release()` 不再清空 JS 层已注册回调，便于释放后重新初始化继续复用监听器
- 新增 `removeAllCallbacks()`，允许业务层主动清空所有 JS 回调

---

## ✅ 验证结果

- Android 真机验证通过，`EVENT_ASR_STARTED` / `EVENT_ASR_PARTIAL_RESULT` / `EVENT_ASR_RESULT` 均可正常收到
- 之前出现的 `240052 / 麦克风错误` 已不再复现
- Expo Android development build 编译通过
