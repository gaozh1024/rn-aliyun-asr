## 🐛 问题修复

### Android AAR 依赖配置调整

**问题描述**: 
在 Gradle 8.x + Android Gradle Plugin 8.x 中，library 模块无法将 AAR 依赖传递给主项目。之前的 `api files()` 方案仍然无法解决编译问题。

**根本原因**:
这是 Google 的官方限制：
> "Direct local .aar file dependencies are not supported when building an AAR."

library 模块打包 AAR 时，无法将本地 AAR 依赖包含进去。

**解决方案**:
采用 React Native 生态的标准做法：

1. **框架侧**：使用 `compileOnly files()` 仅用于本模块编译
2. **用户侧**：在主项目 `android/app/build.gradle` 中手动添加 AAR 依赖

```gradle
// 用户需要在 android/app/build.gradle 中添加：
dependencies {
    implementation files("${rootDir}/../node_modules/@gaozh1024/rn-aliyun-asr/android/libs/nuisdk-release.aar")
}
```

## ⚠️ 破坏性变更

从 v1.0.3 开始，Android 用户必须手动在主项目中添加 AAR 依赖。这是受限于 Gradle 8.x 的强制性变更。

### 迁移指南

**之前 (v1.0.0 - v1.0.2)**:
```gradle
// 不需要手动配置
```

**现在 (v1.0.3+)**:
```gradle
// android/app/build.gradle
dependencies {
    implementation files("${rootDir}/../node_modules/@gaozh1024/rn-aliyun-asr/android/libs/nuisdk-release.aar")
}
```

---

## 升级指南

```bash
npm install @gaozh1024/rn-aliyun-asr@latest
```

然后按照上述迁移指南添加 AAR 依赖。
