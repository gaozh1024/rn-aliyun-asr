## 🐛 问题修复

### Android Gradle 8.x 兼容性修复

**问题描述**:
在 Gradle 8.x + React Native 0.73+ 环境中，`flatDir` 在 library 模块中配置的仓库无法被主项目继承，导致构建时出现错误：
```
Could not find :nuisdk-release:
```

**解决方案**:
将 AAR 依赖方式从 `flatDir` + `implementation(name:)` 改为直接使用 `files()`：

```gradle
// 修改前（不兼容 Gradle 8.x）
repositories {
    flatDir { dirs 'libs' }
}
dependencies {
    implementation(name: 'nuisdk-release', ext: 'aar')
}

// 修改后（兼容 Gradle 8.x）
dependencies {
    implementation files('libs/nuisdk-release.aar')
}
```

**用户影响**:
- ✅ 用户无需再手动在主项目 `android/build.gradle` 中添加 `flatDir` 配置
- ✅ 安装后即可直接构建运行
- ✅ 支持 React Native 0.73+ 和 Gradle 8.x
