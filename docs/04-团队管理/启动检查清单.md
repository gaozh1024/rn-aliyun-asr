### 09:30 开始开发

#### PL 任务

```bash
# 1. 创建 GitHub 仓库
cd ~/Projects
git init rn-aliyun-asr
cd rn-aliyun-asr
git remote add origin https://github.com/gaozh1024/rn-aliyun-asr.git

# 2. 初始化基础文件
cat > README.md << 'EOF'
# @gaozh1024/rn-aliyun-asr

React Native 阿里云实时语音识别 SDK

## 安装

```bash
npm install @gaozh1024/rn-aliyun-asr
```

## 使用

见文档
EOF

# 3. 提交
git add README.md
git commit -m "chore: init project"
git push -u origin main

# 4. 邀请团队成员
# GitHub -> Settings -> Manage access -> Invite
```

#### TS 工程师任务

等待 PL 邀请后：

```bash

cd rn-aliyun-asr
git checkout -b feat/typescript-layer

# 开始开发（参考 开发指南-TypeScript工程师.md）
```
