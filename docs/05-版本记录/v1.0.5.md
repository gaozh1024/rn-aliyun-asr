# v1.0.5 版本说明

**发布日期**: 2026-03-24

---

## 🐛 行为与一致性修复

### Android NativeNui API 对齐

- Android 原生层改为对接 `com.alibaba.idst.nui`
- 使用 `NativeNui.GetInstance()` 与 `initialize/startDialog/stopDialog/cancelDialog`
- `INativeNuiCallback` 回调改为按 `KwsResult` 与 `AsrResult` 解析
- 修复 `stopDialog()` / `cancelDialog()` 调用语义

---

## 🔧 原生与 TS 对齐

### 事件字段对齐（Android/iOS/TS）

- Android 事件补齐 `dialogId` 与 `wakeWord` 字段
- TS 事件数据类型补充 `isFinish` 字段，并在事件映射中接入 `wakeWord/isFinish`
- iOS 事件补充 `wakeWord` 字段

### TS 默认参数与官方示例对齐

- `startRecognition()` 默认模式调整为 `MODE_P2T`
- `initialize()` 后自动下发 `service_type=4` 与 `enable_intermediate_result=true`
- `ASRDialogParams` 增加 `token`，支持启动时刷新 Token
- `cancelRecognition()` 默认改为强制取消，`stopRecognition()` 保持等待最终结果

---

## 🛡️ 稳定性与兼容性

### Android logLevel 防越界

对 `logLevel` 入参进行边界保护，避免非法值导致数组越界崩溃。

### Android NativeEventEmitter 兼容

为 RN 事件订阅补充 `addListener/removeListeners` 空实现，避免部分 RN 版本告警。

### iOS 线程模型修正

- iOS Native Module 改为串行后台队列执行，避免在 UI 线程初始化与控制 SDK
- `stopDialog` 保持使用 `nui_dialog_cancel:NO`，与官方文档“等待最终结果”的语义一致

---

## 📦 发布与工程配置

- Android 构建时自动从 `nuisdk-release.aar` 解压 `classes.jar` 与 JNI 库
- Android 使用方不再需要手动在主项目中追加 AAR 依赖
- README 文档链接改为 GitHub 绝对链接，避免 npm 页面相对链接失效
- 补齐 ESLint/Prettier 配置，确保 `npm run lint` 可用
- `npm test` 在无测试用例时返回成功，便于 CI/发布流程
- 打包内容排除 Android Gradle 缓存目录，减少发布体积
