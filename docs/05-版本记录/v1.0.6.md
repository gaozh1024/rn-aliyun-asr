# v1.0.6 版本说明

**发布日期**: 2026-03-24

---

## 🔧 官方文档对齐修复

### Android NativeNui API 完整对齐

- Android 原生层统一对接 `com.alibaba.idst.nui`
- 使用 `NativeNui.GetInstance()`、`initialize/startDialog/stopDialog/cancelDialog`
- `INativeNuiCallback` 按 `KwsResult` 与 `AsrResult` 解析识别结果
- 构建时自动从 `nuisdk-release.aar` 解压 `classes.jar` 与 JNI 库

### iOS 行为与线程模型修正

- iOS Native Module 改为串行后台队列执行，避免阻塞主线程
- `stopRecognition()` / `cancelRecognition()` 语义与文档保持一致
- 新增批量参数设置能力 `setParams`

---

## 🧩 TS 封装能力增强

- `startRecognition()` 默认模式改为 `MODE_P2T`
- 初始化后自动下发 `service_type=4`
- 默认开启 `enable_intermediate_result`
- `ASRDialogParams` 新增 `token`，支持启动时刷新 Token
- `cancelRecognition()` 默认改为强制取消

---

## 📚 文档与发布准备

- README、API 文档、使用文档、开发文档已同步到最新实现
- 补充发布前最终检查清单与推荐发布命令
- 修复 podspec 与 Git 标签格式不一致问题，统一使用 `v{version}` 标签
