# 发布步骤 - @gaozh1024/rn-aliyun-asr

## 前置条件

确保你已经：
- [ ] 有 NPM 账号
- [ ] 已添加到 @gaozh1024 组织
- [ ] 有发布权限

## 完整发布流程

### 1. 安装依赖（首次）

```bash
npm install
```

### 2. 执行编译

```bash
npm run prepare
```

这会生成 `lib/` 目录，包含：
- `lib/commonjs/` - CommonJS 格式
- `lib/module/` - ES Module 格式
- `lib/typescript/` - TypeScript 声明文件

### 3. 验证编译结果

```bash
ls -la lib/
```

应该看到：
```
lib/
├── commonjs/
│   ├── types.js
│   ├── AliyunASR.js
│   └── index.js
├── module/
│   ├── types.js
│   ├── AliyunASR.js
│   └── index.js
└── typescript/
    ├── types.d.ts
    ├── AliyunASR.d.ts
    └── index.d.ts
```

### 4. 登录 NPM

```bash
npm login
```

### 5. 发布

```bash
npm publish --access public
```

### 6. 验证发布

```bash
npm view @gaozh1024/rn-aliyun-asr
```

## 快速发布（已安装依赖）

如果已经安装过依赖：

```bash
npm run prepare && npm publish --access public
```

- [ ] `package.json` 版本号已更新，当前为 `1.0.5`

- [ ] `README.md` 中版本记录表已包含 `v1.0.5`

- [ ] `npm run lint` 通过
- [ ] `npm test` 通过
- [ ] `npm pack --dry-run` 通过
- [ ] `git status` 仅包含本次准备发布的变更
- [ ] 已提交所有改动

## 推荐发布命令

### 方式一：手动发布

```bash
git add .
git commit -m "chore(release): v1.0.5"
git tag v1.0.5
git push origin main
git push origin v1.0.5
npm publish --access public
```

### 方式二：使用 release-it

```bash
git add .
git commit -m "chore: prepare v1.0.5 release"
npm run release
```

> `release-it` 会按当前配置创建 `v1.0.5` 形式的 Git 标签。

## 发布内容

根据 `package.json` 的 `files` 字段，会发布：

- `src/` - TypeScript 源码
- `lib/` - 编译输出
- `android/` - Android 原生模块（不含 build）
- `ios/` - iOS 原生模块（不含 build）
- `rn-aliyun-asr.podspec`

## 常见问题

### Q1: 提示没有权限？

确保你是 @gaozh1024 组织的成员，且有发布权限。

### Q2: lib/ 目录没有生成？

检查是否执行了 `npm run prepare`，且没有报错。

### Q3: 如何更新版本？

修改 `package.json` 中的 `version` 字段（例如 `1.0.5`），然后重新发布。
