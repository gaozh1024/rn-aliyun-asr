## 安装

### 1. 安装 npm 包

```bash
npm install @gaozh1024/rn-aliyun-asr
# 或
yarn add @gaozh1024/rn-aliyun-asr
```

### 2. iOS 额外配置

```bash
cd ios && pod install
```

### 3. Android 额外配置

**⚠️ 重要：由于 Gradle 8.x 限制，需要手动在主项目中添加 AAR 依赖**

编辑 `android/app/build.gradle`，在 `dependencies` 块中添加：

```gradle
dependencies {
    // ... 其他依赖
    
    // 阿里云语音识别 SDK AAR（必须手动添加）
    implementation files("${rootDir}/../node_modules/@gaozh1024/rn-aliyun-asr/android/libs/nuisdk-release.aar")
}
```

> **说明**：从 Gradle 8.x / Android Gradle Plugin 8.x 开始，library 模块无法直接传递 AAR 依赖。这是 Google 的官方限制，React Native 生态中所有包含 AAR 的库都采用此方案。

### 4. 权限配置

#### Android

在 `android/app/src/main/AndroidManifest.xml` 中添加：

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
```

#### iOS

在 `ios/YourApp/Info.plist` 中添加：

```xml
<key>NSMicrophoneUsageDescription</key>
<string>需要麦克风权限进行语音识别</string>
```

## 快速开始

### 最简示例

```typescript
import { AliyunASR, VadMode, ASREvent } from '@gaozh1024/rn-aliyun-asr';

// 获取实例
const asr = AliyunASR.getInstance();

// 初始化
await asr.initialize({
  appKey: 'your-app-key',
  token: 'your-token',
});

// 监听识别结果
asr.on(ASREvent.ASR_RESULT, (data) => {
  console.log('识别结果:', data.result?.text);
});

// 开始识别
await asr.startRecognition();

// 停止识别
await asr.stopRecognition();

// 释放资源
await asr.release();
```

## API 详解

### 初始化

```typescript
await asr.initialize({
  appKey: 'your-app-key',      // 必填：阿里云 AppKey
  token: 'your-token',         // 必填：访问令牌
  url?: string,                // 可选：自定义服务器地址
  deviceId?: string,           // 可选：设备唯一标识
  workspace?: string,          // 可选：日志目录
  sampleRate?: number,         // 可选：采样率，默认 16000
  format?: 'opus' | 'pcm',     // 可选：音频格式，默认 'opus'
  enableVad?: boolean,         // 可选：启用 VAD，默认 true
  logLevel?: LogLevel,         // 可选：日志级别，默认 INFO
  saveLog?: boolean,           // 可选：保存日志，默认 false
});
```

### 开始识别

```typescript
// 基础使用
await asr.startRecognition();

// 指定 VAD 模式
await asr.startRecognition(VadMode.MODE_VAD);

// 使用热词
await asr.startRecognition(VadMode.MODE_VAD, {
  vocabularyId: 'your-vocabulary-id',
});
```

**VAD 模式说明：**

| 模式 | 说明 |
|------|------|
| `VadMode.MODE_VAD` | 自动检测语音开始和结束（推荐） |
| `VadMode.MODE_P2T` | 按住说话模式 |
| `VadMode.MODE_AUTO_CONTINUAL` | 自动连续识别 |

### 停止/取消识别

```typescript
// 停止识别（不保证返回最终结果）
await asr.stopRecognition();

// 取消识别（不保证返回结果）
await asr.cancelRecognition();

// 强制取消
await asr.cancelRecognition(true);
```

### 事件监听

```typescript
// 临时结果（边说边出）
asr.on(ASREvent.ASR_PARTIAL_RESULT, (data) => {
  console.log('临时结果:', data.result?.text);
});

// 最终结果
asr.on(ASREvent.ASR_RESULT, (data) => {
  console.log('最终结果:', data.result?.text);
});

// 识别错误
asr.on(ASREvent.ASR_ERROR, (data) => {
  console.error('错误:', data.errorMessage);
});

// VAD 事件
asr.on(ASREvent.VAD_START, () => {
  console.log('检测到语音开始');
});

asr.on(ASREvent.VAD_END, () => {
  console.log('检测到语音结束');
});

// 取消监听
asr.off(ASREvent.ASR_RESULT, callback);

// 一次性监听
asr.once(ASREvent.VAD_START, (data) => {
  console.log('语音开始');
});
```

### 释放资源

```typescript
await asr.release();
```

**注意：** 组件卸载时务必调用 release() 释放资源。

## 完整示例

### React Native 组件示例

```typescript
import React, { useEffect, useState, useCallback } from 'react';
import {
  StyleSheet,
  View,
  Text,
  TouchableOpacity,
  ScrollView,
  SafeAreaView,
  Alert,
} from 'react-native';
import { AliyunASR, VadMode, ASREvent, LogLevel } from '@gaozh1024/rn-aliyun-asr';

// 配置
const CONFIG = {
  appKey: 'your-app-key',
  token: 'your-token',
};

const asr = AliyunASR.getInstance();

export default function ASRScreen() {
  const [isInitialized, setIsInitialized] = useState(false);
  const [isRecording, setIsRecording] = useState(false);
  const [results, setResults] = useState<string[]>([]);
  const [currentText, setCurrentText] = useState('');
  const [status, setStatus] = useState('未初始化');

  // 初始化
  const initialize = useCallback(async () => {
    try {
      setStatus('初始化中...');
      await asr.initialize({
        appKey: CONFIG.appKey,
        token: CONFIG.token,
        logLevel: LogLevel.INFO,
      });
      setIsInitialized(true);
      setStatus('已初始化');
    } catch (error) {
      setStatus(`初始化失败: ${error}`);
      Alert.alert('初始化失败', String(error));
    }
  }, []);

  // 释放资源
  const release = useCallback(async () => {
    try {
      await asr.release();
      setIsInitialized(false);
      setStatus('已释放');
    } catch (error) {
      Alert.alert('释放失败', String(error));
    }
  }, []);

  // 开始识别
  const start = useCallback(async () => {
    try {
      await asr.startRecognition(VadMode.MODE_VAD);
      setIsRecording(true);
      setCurrentText('');
      setStatus('识别中...');
    } catch (error) {
      Alert.alert('开始识别失败', String(error));
    }
  }, []);

  // 停止识别
  const stop = useCallback(async () => {
    try {
      await asr.stopRecognition();
      setIsRecording(false);
      setStatus('已停止');
    } catch (error) {
      Alert.alert('停止识别失败', String(error));
    }
  }, []);

  // 设置事件监听
  useEffect(() => {
    // 临时结果
    asr.on(ASREvent.ASR_PARTIAL_RESULT, (data) => {
      if (data.result?.text) {
        setCurrentText(data.result.text);
      }
    });

    // 最终结果
    asr.on(ASREvent.ASR_RESULT, (data) => {
      if (data.result?.text) {
        setResults(prev => [...prev, data.result!.text]);
        setCurrentText('');
      }
    });

    // 错误处理
    asr.on(ASREvent.ASR_ERROR, (data) => {
      setStatus(`错误: ${data.errorMessage}`);
      setIsRecording(false);
    });

    // 清理
    return () => {
      asr.release().catch(console.error);
    };
  }, []);

  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.title}>实时语音识别</Text>
      <Text style={styles.status}>状态: {status}</Text>

      <View style={styles.buttonContainer}>
        {!isInitialized ? (
          <TouchableOpacity style={styles.button} onPress={initialize}>
            <Text style={styles.buttonText}>初始化</Text>
          </TouchableOpacity>
        ) : (
          <>
            <TouchableOpacity
              style={[styles.button, isRecording && styles.buttonActive]}
              onPress={isRecording ? stop : start}
            >
              <Text style={styles.buttonText}>
                {isRecording ? '停止' : '开始'}
              </Text>
            </TouchableOpacity>

            <TouchableOpacity 
              style={[styles.button, styles.dangerButton]} 
              onPress={release}
            >
              <Text style={styles.buttonText}>释放</Text>
            </TouchableOpacity>
          </>
        )}
      </View>

      {currentText ? (
        <View style={styles.currentContainer}>
          <Text style={styles.currentLabel}>当前:</Text>
          <Text style={styles.currentText}>{currentText}</Text>
        </View>
      ) : null}

      <Text style={styles.resultLabel}>识别历史:</Text>
      <ScrollView style={styles.resultContainer}>
        {results.map((text, index) => (
          <View key={index} style={styles.resultItem}>
            <Text style={styles.resultIndex}>{index + 1}.</Text>
            <Text style={styles.resultText}>{text}</Text>
          </View>
        ))}
      </ScrollView>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    padding: 16,
    backgroundColor: '#f5f5f5',
  },
  title: {
    fontSize: 24,
    fontWeight: 'bold',
    textAlign: 'center',
    marginBottom: 8,
  },
  status: {
    fontSize: 14,
    color: '#666',
    textAlign: 'center',
    marginBottom: 16,
  },
  buttonContainer: {
    gap: 12,
    marginBottom: 16,
  },
  button: {
    backgroundColor: '#1890ff',
    paddingVertical: 12,
    paddingHorizontal: 24,
    borderRadius: 8,
    alignItems: 'center',
  },
  buttonActive: {
    backgroundColor: '#ff4d4f',
  },
  dangerButton: {
    backgroundColor: '#ff4d4f',
  },
  buttonText: {
    color: '#fff',
    fontSize: 16,
    fontWeight: '600',
  },
  currentContainer: {
    backgroundColor: '#fff',
    padding: 16,
    borderRadius: 8,
    marginBottom: 16,
  },
  currentLabel: {
    fontSize: 14,
    color: '#666',
    marginBottom: 4,
  },
  currentText: {
    fontSize: 18,
    color: '#1890ff',
  },
  resultLabel: {
    fontSize: 16,
    fontWeight: '600',
    marginBottom: 8,
  },
  resultContainer: {
    flex: 1,
    backgroundColor: '#fff',
    borderRadius: 8,
    padding: 12,
  },
  resultItem: {
    flexDirection: 'row',
    paddingVertical: 8,
    borderBottomWidth: 1,
    borderBottomColor: '#f0f0f0',
  },

    width: 30,

  },

  },
});
```

## 常见问题

### Q1: 初始化失败，提示 "认证失败"？

**原因：** Token 过期或无效

**解决：**
1. 从阿里云控制台获取新的 Token
2. 确保 AppKey 和 Token 匹配
3. 检查网络连接

```typescript
// Token 刷新示例
asr.on(ASREvent.ASR_ERROR, async (data) => {
  if (data.errorCode === ASRErrorCode.AUTH_FAILED) {
    const newToken = await fetchNewToken();
    await asr.release();
    await asr.initialize({
      appKey: CONFIG.appKey,
      token: newToken,
    });
  }
});
```

### Q2: 麦克风权限被拒绝？

**解决：**

Android: 在 `AndroidManifest.xml` 中添加权限，并在运行时申请。

iOS: 在 `Info.plist` 中添加 `NSMicrophoneUsageDescription`。

```typescript
import { PermissionsAndroid, Platform } from 'react-native';

const requestAudioPermission = async () => {
  if (Platform.OS === 'android') {
    const granted = await PermissionsAndroid.request(
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
      {
        title: '麦克风权限',
        message: '需要麦克风权限进行语音识别',
        buttonPositive: '确定',
      }
    );
    return granted === PermissionsAndroid.RESULTS.GRANTED;
  }
  return true;
};
```

### Q3: 识别结果不准确？

**优化建议：**
1. 使用热词定制
2. 确保环境噪音较小
3. 说话清晰、语速适中

```typescript
await asr.startRecognition(VadMode.MODE_VAD, {
  vocabularyId: 'your-vocabulary-id',
});
```

### Q4: 内存泄漏警告？

**原因：** 组件卸载时未释放资源

**解决：**

```typescript
useEffect(() => {
  // ... 设置监听
  
  return () => {
    // 组件卸载时释放资源
    asr.release().catch(console.error);
  };
}, []);
```

### Q5: iOS 编译失败？

**常见原因：**
1. Framework 未正确链接
2. 资源文件未添加到 Bundle

**解决：**
1. 确保执行了 `pod install`
2. 在 Xcode 中检查 Framework 是否正确引用
3. 检查资源文件是否在 Copy Bundle Resources 中

## 最佳实践

### 1. 单例模式

使用 `getInstance()` 获取单例，避免创建多个实例：

```typescript
const asr = AliyunASR.getInstance();
```

### 2. 错误处理

始终添加错误监听：

```typescript
asr.on(ASREvent.ASR_ERROR, (data) => {
  console.error('ASR 错误:', data.errorMessage);
  // 根据错误码处理
  switch (data.errorCode) {
    case ASRErrorCode.AUTH_FAILED:
      // 刷新 Token
      break;
    case ASRErrorCode.MIC_ERROR:
      // 检查权限
      break;
  }
});
```

### 3. 生命周期管理

在组件卸载时释放资源：

```typescript
useEffect(() => {
  return () => {
    asr.release().catch(console.error);
  };
}, []);
```

### 4. 性能优化

- 使用 `LogLevel.ERROR` 或 `LogLevel.NONE` 减少日志输出
- 及时取消不需要的事件监听
- 避免频繁初始化和释放

```typescript
await asr.initialize({
  // ...
  logLevel: LogLevel.ERROR,  // 生产环境
});
```
