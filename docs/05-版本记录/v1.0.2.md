## 🐛 问题修复

### Android AAR 依赖传递修复

**问题描述**: 
`v1.0.1` 虽然解决了配置阶段的问题，但在编译时主项目仍找不到 AAR 中的类（`com.alibaba.nuisdk` 不存在）。

**根本原因**:
在 Gradle 8.x + Android Gradle Plugin 8.x 中，library 模块使用 `implementation files()` 不会将 AAR 依赖传递给主项目。

**修复方案**:
1. 使用 `api` 代替 `implementation`，使依赖可传递
2. 添加 `afterEvaluate` 配置确保 AAR 被正确打包

```gradle
// 修改后
dependencies {
    api files('libs/nuisdk-release.aar')
}

project.afterEvaluate {
    if (project.hasProperty("android")) {
        project.android.libraryVariants.all { variant ->
            variant.processJavaResourcesProvider.configure { task ->
                task.from(file('libs/nuisdk-release.aar'))
            }
        }
    }
}
```

## ⚠️ 重要说明

如果 `v1.0.2` 仍然无法编译，请手动在主项目中添加 AAR 依赖：

**在 `android/app/build.gradle` 中添加**：

```gradle
dependencies {
    // ... 其他依赖
    
    // 阿里云语音识别 SDK AAR
    implementation files("${rootDir}/../node_modules/@gaozh1024/rn-aliyun-asr/android/libs/nuisdk-release.aar")
}
```
