# v1.0.7 版本说明

**发布日期**: 2026-03-24

---

## 🛠 Android 识别链路修复

### 识别模式与录音参数修正

- `service_type` 默认从 `4` 调整为 `0`，默认走普通 ASR 模式
- `ASRInitConfig` 新增 `serviceType` 配置，支持 `asr` / `speechTranscriber`
- `enable_recorder_by_user` 默认改为 `false`，避免未喂音频时无结果返回

### 资源与初始化补强

- Android 资源补齐 `kws.bin` 与 `ali_copylist.txt`
- 初始化时自动复制 Android assets 到应用私有目录
- `workspace` / `debug_path` 自动兜底到 App 可写目录
- 初始化增加幂等处理，遇到 `240012` 会自动释放并重试

### 事件链路增强

- 原生事件新增 `eventName`
- `ASREvent` 枚举值修正为与 `Constants.NuiEvent.ordinal()` 一致
- 原生回调增加详细调试日志，便于排查“有录音无识别结果”问题

---

## 🔧 TS 封装增强

- `initialize()` 改为幂等，重复调用会先自动释放再重建
- `ASREventData` 增加 `eventName`
- JS 事件分发优先按 `eventName` 解析，降低对 ordinal 的依赖

---

## 📚 文档与发布准备

- API 文档与开发文档同步到最新参数和事件定义
- 发布版本升级到 `1.0.7`
