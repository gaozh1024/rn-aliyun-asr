## 精简后的功能范围

本框架仅支持**实时语音识别**，不包含以下功能：
- ❌ 语音合成 (TTS)
- ❌ 文件转写
- ❌ 一句话识别（已移除 Promise 封装，使用普通识别模式）
- ❌ 语音唤醒
- ❌ 声纹识别
- ❌ 语音评测

## SDK 资源位置

```
docs/
├── android/
│   ├── RelWithDebugInfo/
│   │   ├── nuisdk-release.aar      # Android SDK
│   │   └── android_include/        # C++ 头文件
│   └── resources/                  # 资源文件（仅 ASR 必需）
│       ├── nui.json
│       ├── cei.json
│       └── vad.bin
└── ios/
    ├── Release/
    │   └── nuisdk.framework/       # iOS SDK
    └── resources/                  # 资源文件（仅 ASR 必需）
        ├── nui.json
        ├── cei.json
        └── vad.bin
```

**注意**：TTS 相关资源（`tts/` 目录、`kws.bin` 等）不需要复制。
